## Estrutura dos Pacotes

Cada tarball individual contém:

```
{entidade}-voices-v1.0.0/
  wavs/                        # Todos os áudios gerados
  top_10_selection/             # Top 10 selecionados + unified_reference.wav
  metadata.json                # Scores, parâmetros de geração, timestamps
  metadata.csv                 # Formato LJSpeech
  chatterbox_data.jsonl         # Formato Chatterbox fine-tuning
  coqui_manifest.json           # Formato Coqui TTS
```

## Uso dos Áudios de Referência

O diretório `top_10_selection/` contém os 10 melhores áudios selecionados por qualidade e diversidade, além do arquivo `unified_reference.wav` que concatena todos os selecionados em um único áudio.

Para fine-tuning com Chatterbox:

```bash
tar xzf luna-voices-v1.0.0.tar.gz
cd luna-voices-v1.0.0/top_10_selection/
# Use unified_reference.wav como referência de voz
# Use chatterbox_data.jsonl para o treinamento
```

Para fine-tuning com Coqui TTS:

```bash
tar xzf luna-voices-v1.0.0.tar.gz
cd luna-voices-v1.0.0/
# Use coqui_manifest.json como manifesto do dataset
# Os áudios estão em wavs/
```
